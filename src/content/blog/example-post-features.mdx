use **bold**, _italics_, `inline code`, [links](https://astro.build) and ~~strikethrough~~. Footnotes turn into

## Headings and the table of contents

Every `##` and `###` heading shows up in the table of contents. On large screens it sits in the left column with
a line that fills as you read, and it tells you how many minutes are left. On mobile it folds up at the top.
Hover a heading to see its link; clicking it also copies the link.

### A third-level heading

Use `###` for subsections. Avoid going deeper than `####`; if you need to, the section probably wants to be split.

## Code blocks

Code is highlighted at build time (no JavaScript shipped) and switches with the colour theme. Add
`title="file.py"` after the language for a file name, and `{4-5}` to highlight lines:

```python title="losses.py" {4-5}
import numpy as np


def log_softmax(logits: np.ndarray) -> np.ndarray:
    """Numerically stable log-softmax along the last axis."""
    shifted = logits - logits.max(axis=-1, keepdims=True)
    return shifted - np.log(np.exp(shifted).sum(axis=-1, keepdims=True))


def cross_entropy(logits: np.ndarray, targets: np.ndarray) -> float:
    log_probs = log_softmax(logits)
    return float(-log_probs[np.arange(len(targets)), targets].mean())
```

To show a change, mark lines with `// [!code ++]` and `// [!code --]` comments (`# [!code ++]` in Python).
The copy button leaves out removed lines:

```ts title="retry.ts"
type RetryOptions = { retries?: number; baseDelayMs?: number };

export async function withRetry<T>(
  fn: () => Promise<T>,
  { retries = 3, baseDelayMs = 250 }: RetryOptions = {},
): Promise<T> {
  for (let attempt = 0; ; attempt++) {
    try {
      return await fn();
    } catch (error) {
      if (attempt >= retries) throw error;
      const delay = baseDelayMs * 2 ** attempt; // [!code --]
      const delay = baseDelayMs * 2 ** attempt * (0.5 + Math.random()); // [!code ++]
      await new Promise((resolve) => setTimeout(resolve, delay));
    }
  }
}
```

## Math

Inline math uses single dollars: the softmax of a logit vector $z \in \mathbb{R}^K$ is
$\sigma(z)_i = e^{z_i} / \sum_j e^{z_j}$. Display math uses double dollars, gets a number, and has a button to
copy its TeX source when you hover it:

$$
\mathcal{L}(\theta) = -\frac{1}{N} \sum_{n=1}^{N} \log \frac{\exp\left(f_\theta(x_n)_{y_n}\right)}{\sum_{k=1}^{K} \exp\left(f_\theta(x_n)_k\right)}
$$

$$
\theta_{t+1} = \theta_t - \eta \, \nabla_\theta \mathcal{L}(\theta_t)
$$

Equation (2) is plain gradient descent, the same thing the dots on the home page are doing.[^3] The KaTeX
stylesheet is only loaded on posts that contain math.
